# Threads Copilot

Telegram-бот для управления публикациями в Threads.

Первый этап: постоянная нижняя клавиатура 2×2 — «▶️ Постинг»,
«▶️ Автоответ», «📊 Статистика», «⚙️ Настройки».
Команды `/start` и `/menu` показывают меню. Кнопки пока отвечают
сообщениями-заглушками; публикации и автоответы ещё не запускаются.

## Запуск

Нужен Python 3.11 или новее.

```sh
python -m pip install -r requirements.txt
python bot.py
```

Перед запуском задайте `TELEGRAM_BOT_TOKEN` в окружении.
Секреты в репозиторий не добавляются; `.env` автоматически не загружается.

## Railway

Подключите репозиторий к сервису и задайте `TELEGRAM_BOT_TOKEN` в Variables.
Команда запуска задана в `railway.json`. Бот работает через long polling:
держите одну реплику и не запускайте другой процесс с тем же токеном.
У токена не должно быть активного webhook.

Postgres для текущего меню не требуется. Настройки и состояния пока
не сохраняются. Публикация постов, автоответы и статистика будут добавлены отдельно.
