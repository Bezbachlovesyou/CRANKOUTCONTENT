# Threads Copilot

Telegram-бот для управления публикациями в Threads.

Первый этап: постоянная нижняя клавиатура 2×2 — «▶️ Постинг»,
«▶️ Автоответ», «📊 Статистика», «⚙️ Настройки».
Команды `/start` и `/menu` показывают меню. Публикации, автоответы и статистика
пока отвечают заглушками. Настройки открывают экран с редактированием параметров.

## Запуск

Нужен Python 3.11 или новее.

```sh
python -m pip install -r requirements.txt
python bot.py
```

Перед запуском задайте `TELEGRAM_BOT_TOKEN` в окружении.
Секреты в репозиторий не добавляются; `.env` автоматически не загружается.

## Railway

Подключите репозиторий к сервису и задайте `TELEGRAM_BOT_TOKEN` в Variables.
Команда запуска задана в `railway.json`. Бот работает через long polling:
держите одну реплику и не запускайте другой процесс с тем же токеном.
У токена не должно быть активного webhook.

Для сохранения настроек задайте `DATABASE_URL` и `ADMIN_TELEGRAM_ID` (числовой
Telegram ID владельца). Примените схему к новой базе:

```sh
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f schema.sql
```

Без базы меню работает, но настройки не сохраняются; бот явно предупреждает об этом.
Ожидание ввода хранится в памяти: после перезапуска повторно выберите параметр.
Сохранённые настройки остаются в Postgres. Публикации и автоответы ещё не запускаются.
Правила персоны и контент-плана описаны в [docs/product.md](docs/product.md).
